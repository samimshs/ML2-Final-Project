# DeepEyes Local Detector

This is the notebook Step 6 detector copied as a standalone Python script. It is for local Mac/Windows execution, not Netlify static hosting.

Run from the project root after installing the notebook requirements:

```bash
python "For Deployment/local_detector/deepeyes_detector.py"
```

The script expects:

```text
models/deep_eyes_cnn_v1.keras
sounds/beep.wav
```
