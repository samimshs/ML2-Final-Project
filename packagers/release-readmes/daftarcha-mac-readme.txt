Daftarcha for macOS - Read Me

Files in this download:
- Installer - Daftarcha.dmg
- Read Me - macOS.txt

Install steps:
1. Open "Installer - Daftarcha.dmg".
2. Drag Daftarcha into the Applications folder.
3. Open Daftarcha from Applications.
4. If macOS says Apple cannot verify the app, right-click Daftarcha, choose Open, then confirm Open.

Note:
This build is not Apple notarized yet, so macOS may show a security warning. The app stores business data locally on your computer. If you need help, contact samimshs@gmail.com.
