Daftarcha for Windows - Read Me

Files in this download:
- Installer - Daftarcha.exe
- Read Me - Windows.txt

Install steps:
1. Double-click "Installer - Daftarcha.exe".
2. If Windows SmartScreen appears, choose More info, then Run anyway.
3. Choose the folder where you want to install Daftarcha.
4. Finish the installer.
5. Open Daftarcha from the desktop shortcut or Start Menu.

Uninstall:
Use Windows Settings > Apps, or the Daftarcha uninstall shortcut in the Start Menu.

Note:
This build is not code-signed yet, so Windows may show a publisher warning. If you need help, contact samimshs@gmail.com.
