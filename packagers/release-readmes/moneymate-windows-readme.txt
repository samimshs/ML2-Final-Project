MoneyMate for Windows - Read Me

Files in this download:
- Installer - MoneyMate.exe
- Read Me - Windows.txt

Install steps:
1. Double-click "Installer - MoneyMate.exe".
2. If Windows SmartScreen appears, choose More info, then Run anyway.
3. Choose the folder where you want to install MoneyMate.
4. Finish the installer.
5. Open MoneyMate from the desktop shortcut or Start Menu.

Password:
MoneyMate does not ship with a preset password. Create your own local account and password when you first open the app. You can change the password later in Settings.

Uninstall:
Use Windows Settings > Apps, or the MoneyMate uninstall shortcut in the Start Menu.

Note:
This build is not code-signed yet, so Windows may show a publisher warning. If you need help, contact samimshs@gmail.com.
